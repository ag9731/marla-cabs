# Design System

## Core Aesthetic
- **Vibe:** Clean, modern, trustworthy travel/cab aesthetic.
- **Tone:** Professional but warm and human.
- **Layout:** Plenty of white space, large readable typography, mobile-first responsive design.

## Color Palette
- **Primary:** Deep Navy (`#0F172A`)
- **Accent:** Vibrant Amber/Orange (`#F59E0B`)
- **Backgrounds:** White (`#FFFFFF`), Very Light Gray (`#F8FAFC`)
- **Text:** Slate (`#334155` for body, `#0F172A` for headings)

## Typography
- Use modern sans-serif fonts (e.g., Inter or Geist).
- Strong heading hierarchy.

## UI Elements
- **Buttons:** Large, accessible, clear CTA with subtle hover effects. Primary buttons use the Accent color; secondary buttons use the Primary color.
- **Cards:** Clean borders, soft shadows, rounded corners (`rounded-xl` or `rounded-2xl`).
- **Icons:** Lucide React icons.
- **Animations:** Subtle Framer Motion animations (fade-ins, slide-ups on scroll) for a premium feel.

## Image Guidelines (CRITICAL)
- Do NOT use random images from Google search.
- Only use free, commercially usable images from Unsplash (preferred), Pexels, or Pixabay.
- For every image, add a comment in the code with the source URL and photographer credit.
- Use Next.js `<Image>` component with proper width, height, and descriptive alt text.
- Prefer high-quality images of modern cars, Indian cities/airports, professional drivers, families, corporate travellers, and wedding cars.
