# Project Context

**Project Name:** Marla Cabs
**Phase:** Phase 0 (Initial Go-Live Version)
**Target Market:** India

## Project Goal
To build a professional, SEO-optimized, content-rich online cab booking marketing website. Phase 0 serves as a high-converting landing platform and informational site. It focuses on lead generation through enquiry/booking forms rather than a full-fledged booking engine.

## Key Features (Phase 0)
- **Marketing & SEO Pages**: Home, Services, Fleet, About, Blog.
- **Booking Enquiry Flow**: A robust contact/booking form using EmailJS to capture leads.
- **Content Strategy**: Rich, human-like content targeting local SEO keywords (airport taxi, outstation cab, local sightseeing).

## Future Phases
- **Phase 1+**: Implementation of a real booking engine, user/driver dashboards, payment gateway integrations, and Supabase backend.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui, Radix UI
- **Icons & Animations**: Lucide React, Framer Motion
- **Forms**: React Hook Form, Zod
- **Email**: EmailJS (for Phase 0 form submissions)
